> **مشروع تجريبي.** يصف القالب الذي بُني عليه هذا الموقع. عدّله ليصف نسختك، أو احذفه.

## المشكلة

تحتاج العلامة الشخصية إلى بيت واحد للمشاريع والكتابة: مجاني الاستضافة، وسريع، وسهل التحديث، ويدعم أكثر من لغة.

## الأهداف

- موقع احترافي لعرض الأعمال ومدوّنة تقنية بالعربية والإنجليزية.
- إضافة المحتوى كملفات Markdown دون تعديل الشيفرة في التحديثات المعتادة.
- استضافة مجانية على GitHub Pages ونشر تلقائي.

## كيف يعمل

يولّد Astro صفحات HTML ثابتة وقت البناء. المقالات والمشاريع ملفات Markdown يتحقق منها مخطّط (schema). وقدر قليل من JavaScript يشغّل زر المظهر والقائمة في الجوال والتصفية والبحث، وكل ذلك داخل المتصفح، فلا حاجة إلى خادم أو قاعدة بيانات.

## ملاحظات التنفيذ

- يُعالَج التخطيط من اليمين إلى اليسار بخصائص CSS المنطقية.
- تحدّد كل صفحة أي النسخ اللغوية موجودة فعلًا، فلا تشير الروابط ووسوم `hreflang` إلى صفحات غير موجودة.
- يبني سير عمل GitHub Actions الموقع وينشره عند كل دفع للتغييرات.

## الدروس المستفادة

التصميم لاتجاه اليمين إلى اليسار منذ البداية أسهل بكثير من إضافته لاحقًا، والمخطّط الخاص بالمحتوى يلتقط الأخطاء قبل وصولها إلى الموقع المنشور.

## تحسينات مستقبلية

- إضافة صورة شخصية حقيقية وسيرة ذاتية.
- نشر مزيد من المقالات والمشاريع.
- ربط نطاق خاص.
