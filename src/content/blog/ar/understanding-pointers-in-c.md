## ما هو المؤشّر؟

المؤشّر (pointer) متغيّر يخزّن **عنوانًا في الذاكرة** بدلًا من قيمة عادية. لكل متغيّر مكان في الذاكرة، والمؤشّر يتيح لك الاحتفاظ بهذا المكان والتعامل مع البيانات المخزّنة فيه.

```c
#include <stdio.h>

int main(void) {
    int score = 42;
    int *p = &score;   // p holds the address of score

    printf("value of score  : %d\n", score);
    printf("address of score: %p\n", (void *)&score);
    printf("value of p      : %p\n", (void *)p);
    printf("value at *p     : %d\n", *p);

    *p = 100;          // change score through the pointer
    printf("score is now    : %d\n", score);
    return 0;
}
```

شغّل المثال وستلاحظ أن `p` و`&score` يطبعان العنوان نفسه، وأن الكتابة عبر `*p` تغيّر قيمة `score`.

## ثلاثة رموز يجب تذكّرها

- `int *p` يعلن أن `p` مؤشّر إلى عدد صحيح `int`.
- `&x` هو معامل **العنوان**: يعطيك عنوان `x`.
- `*p` هو معامل **فكّ الإشارة** (dereference): يعطيك القيمة المخزّنة في العنوان الموجود داخل `p`.

يظهر الرمز `*` بدورين: في التصريح يعني «مؤشّر إلى»، وفي التعبير يعني «الشيء الذي يشير إليه المؤشّر».

## لماذا نحتاج المؤشّرات؟ تعديل متغيّر المُستدعي

تمرّر لغة C الوسائط **بالقيمة**، فتستقبل الدالة نسخة عادةً. ولكي تعدّل الدالة المتغيّر الأصلي، مرِّر عنوانه.

```c
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);      // x is now 2, y is now 1
    return 0;
}
```

## المؤشّرات والمصفوفات

اسم المصفوفة يتحوّل عادةً إلى مؤشّر يشير إلى عنصرها الأول، والتعبير `a[i]` معرَّف بأنه `*(a + i)`. وتُحسب العمليات الحسابية على المؤشّرات بحسب حجم نوع العنصر، فالتعبير `p + 1` ينتقل إلى `int` التالي وليس إلى البايت التالي.

```c
int nums[] = {10, 20, 30};
int *p = nums;

printf("%d\n", *(p + 2));   // 30
printf("%d\n", p[2]);       // 30 — same thing
```

## أخطاء شائعة

1. **مؤشّرات غير مهيّأة.** المؤشّر الذي لم تعيّن قيمته يشير إلى مكان عشوائي. هيّئه بعنوان صالح أو بالقيمة `NULL`.
2. **فكّ إشارة `NULL`.** تحقّق من المؤشّر قبل استخدامه إذا كان من الممكن أن يكون `NULL`.
3. **المؤشّرات المعلّقة.** إرجاع عنوان متغيّر محلي، أو استخدام ذاكرة بعد `free`، يتركك أمام مؤشّر إلى شيء لم يعد موجودًا.
4. **تجاوز الحدود.** القراءة أو الكتابة بعد نهاية المصفوفة سلوك غير معرَّف.
5. **تسرّب الذاكرة.** كل `malloc` ناجح يحتاج إلى `free` مقابل.

## أفكار للتدريب

- اكتب الدالة `strlen` بنفسك باستخدام مؤشّر يتقدّم حتى يصل إلى `'\0'`.
- اعكس مصفوفة في مكانها باستخدام مؤشّرين، واحد من كل طرف.
- اطبع عناوين عناصر متتالية في مصفوفة وتأكّد أن الفارق بينها يساوي `sizeof(int)`.

تبدو المؤشّرات غريبة في البداية لأنها تجعل الذاكرة مرئية. ارسم مربعات وأسهمًا على الورق أثناء التدرّب؛ فهذا يفيد أكثر مما تتوقع.
