## Hi, I'm the person behind MEZO TECH

I'm a software engineer in the making and a technology enthusiast. MEZO TECH is where I keep a public notebook: what I'm learning, what I'm building, and what goes wrong along the way.

## My technology journey

I like understanding how things work underneath — how a program uses memory, how a website reaches a browser, how a tiny chip can read a sensor. I'd rather build something small and learn from it than collect certificates of things I haven't tried.

## What interests me

- **Software engineering** — writing code that is clear, tested and maintainable.
- **Programming** — starting from C and Python, and learning how languages differ.
- **Artificial intelligence** — understanding the fundamentals, not just using the tools.
- **Embedded systems and electronics** — where software meets the physical world.
- **Practical projects** — every project teaches something a tutorial can't.

## Current goals

- Build and finish more small projects.
- Write about what I learn so that I understand it properly.
- Get comfortable with professional workflows such as Git, code review and testing.
